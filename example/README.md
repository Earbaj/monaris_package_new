# Moneris Payment Example

A complete demonstration of how to integrate and use the `moneris_payment` package in a Flutter application.

## Getting Started

1. Set up your backend preload and receipt endpoints following the documentation in the main package README.
2. Update the `preloadUrl` and `receiptUrl` in `lib/main.dart` with your endpoints.
3. Run the example app:

```bash
flutter run
```
